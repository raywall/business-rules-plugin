# Samples

Exemplos de scripts YAML para usar em blocos `rules` no Obsidian ou no simulador web.

Formato de uso:

````markdown
```rules
# cole aqui o conteudo de um dos arquivos .yaml
```
````

Arquivos:

- `ecommerce-order-review.yaml`: aprovacao de pedido com cliente, estoque, cupom e risco.
- `refund-request.yaml`: aprovacao automatica de reembolso.
- `saas-plan-upgrade.yaml`: upgrade de plano SaaS com calculo de prorata.
- `insurance-claim-triage.yaml`: triagem de sinistro com documentos e antifraude.
- `support-ticket-routing.yaml`: roteamento de ticket com SLA e fila.
